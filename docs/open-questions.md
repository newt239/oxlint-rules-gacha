## 未確認のリスク

| 項目                       | 内容                                                                               | 対応                                                                                     |
| -------------------------- | ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| ビルド環境からの外部 fetch | `oxc.rs` への到達可否が未確認（ローカルからは到達できている）                      | 初回デプロイで実測。不可なら生成物をコミットする方式へ（[フェーズ 7](./phase-7-cd.md)）  |
| npm 11 の `allowScripts`   | 依存更新のたびにインストールスクリプトの再承認が要る。ビルド環境で引っかかる可能性 | 初回デプロイのログで確認                                                                 |
| 非公式プラグインへの依存   | `@stylexswc/*` は StyleX / Next.js の更新に追従が遅れる可能性                      | バージョン固定。Dependabot のまとめ更新から除外済み                                      |
| ドキュメント構造の変更     | oxc.rs のパス・Markdown 構造が変わるとパイプラインが壊れる                         | 単体テスト + `rules:build` のしきい値チェック + 週次実行で早期検知                       |
| 自動 a11y テストなし       | 退行に気づきにくい                                                                 | [フェーズ 8](./phase-8-a11y-and-performance.md) のチェックリストをリリース前に手動で消化 |
