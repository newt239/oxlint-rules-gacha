# 未決事項

判断が必要な項目と、判断のタイミング。

## 判断待ち

| 項目                    | 内容                                                                                                                                     | いつ決めるか                                          |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| ドメイン名              | 未定。`NEXT_PUBLIC_SITE_URL` が未設定のうちは `http://localhost:3000` が `metadataBase` になり、OGP の絶対 URL が壊れる                  | [フェーズ 6](./phase-6-i18n-and-rule-pages.md) までに |
| ロゴ                    | 未定。現在は `src/app/icon.svg` がテンプレートのまま                                                                                     | [フェーズ 3](./phase-3-design.md) 前後                |
| `nursery` の既定扱い    | 仕様書では「既定で除外」。実験的ルールなので既定オフが妥当だが、コレクションの分母に含めるかは別問題                                     | [フェーズ 2](./phase-2-draw.md)                       |
| OGP の縮退              | 1740 枚の生成がビルド時間制限に収まるか。超える場合は代表画像 1 枚にする                                                                 | [フェーズ 6](./phase-6-i18n-and-rule-pages.md) で実測 |
| `zod` の導入            | アプリ本体では不要。`scripts/build-rules.ts` のパース結果検証に使うと壊れ方が分かりやすくなる。入れるならビルド時のみの依存              | [フェーズ 1](./phase-1-data-pipeline.md)              |
| `react-aria-components` | ガチャ UI に必要な対話要素はボタンとトグル程度で素の要素で足りる見込み。フィルタ設定に複雑なコンポーネントを使いたくなった場合のみ再検討 | 必要になったとき                                      |
| 日本語フォント          | Zen Maru Gothic に `japanese` サブセットが無く、日本語グリフが配信されない可能性がある                                                   | [フェーズ 6](./phase-6-i18n-and-rule-pages.md)        |
