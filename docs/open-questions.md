# 未決事項

判断が必要な項目と、判断のタイミング。

## 判断待ち

| 項目                    | 内容                                                                                                                                                                                               | いつ決めるか                                   |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| ドメイン名              | 未定。`NEXT_PUBLIC_SITE_URL` が未設定のうちは `http://localhost:3000` が `metadataBase` になり、OGP の絶対 URL が壊れる                                                                            | デプロイまでに                                 |
| ロゴ                    | 未定。現在は `src/app/icon.svg` がテンプレートのまま                                                                                                                                               | デプロイまでに                                 |
| 日本語フォント          | Zen Maru Gothic に `japanese` サブセットが無く、日本語グリフが配信されない可能性がある                                                                                                             | [フェーズ 6](./phase-6-i18n-and-rule-pages.md) |
| `react-aria-components` | ガチャ UI に必要な対話要素はボタンとトグル程度で素の要素で足りている。フィルタ設定に複雑なコンポーネントを使いたくなった場合のみ再検討                                                             | 必要になったとき                               |
| OGP 画像の事前生成      | `generateStaticParams` でも `dynamic = "force-static"` でもビルド時には出力されず、初回リクエストで生成してキャッシュする方式になっている。静的ホスティングへ移す場合は代表画像 1 枚への縮退が要る | ホスティング先を決めるとき                     |

## 未確認のリスク

| 項目                       | 内容                                                                               | 対応                                                                                     |
| -------------------------- | ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| ビルド環境からの外部 fetch | `oxc.rs` への到達可否が未確認（ローカルからは到達できている）                      | 初回デプロイで実測。不可なら生成物をコミットする方式へ（[フェーズ 7](./phase-7-cd.md)）  |
| npm 11 の `allowScripts`   | 依存更新のたびにインストールスクリプトの再承認が要る。ビルド環境で引っかかる可能性 | 初回デプロイのログで確認                                                                 |
| 非公式プラグインへの依存   | `@stylexswc/*` は StyleX / Next.js の更新に追従が遅れる可能性                      | バージョン固定。Dependabot のまとめ更新から除外済み                                      |
| ドキュメント構造の変更     | oxc.rs のパス・Markdown 構造が変わるとパイプラインが壊れる                         | 単体テスト + `rules:build` のしきい値チェック + 週次実行で早期検知                       |
| ルール説明が英語のみ       | 日本語 UI での体験が中途半端になる可能性                                           | 注記を明示。反応を見て主要ルールのみ翻訳を検討                                           |
| 自動 a11y テストなし       | 退行に気づきにくい                                                                 | [フェーズ 8](./phase-8-a11y-and-performance.md) のチェックリストをリリース前に手動で消化 |

## 決着済み

| 項目                            | 結論                                                                                                                   |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `--cat-pedantic` のコントラスト | 5.27:1（cabinet）/ 4.65:1（cabinet-2）。**調整不要**                                                                   |
| StyleX の CSS 抽出              | Turbopack + `@stylexswc/postcss-plugin` で動作を確認済み                                                               |
| ルール件数                      | 612 ではなく **870**（15 プラグイン）                                                                                  |
| App Router の位置               | `src/app/`（仕様書 §15 の `app/` ではない）                                                                            |
| `zod` の導入                    | **導入した**。`scripts/` のみで使うビルド時依存                                                                        |

| OGP 画像のフォント              | `ImageResponse` はフォント未指定でも既定のサンセリフで描画される。フォントの同梱はしない                               |
