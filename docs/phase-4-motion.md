# フェーズ 4: 演出

**完了条件**: §7 のシーケンスが動き、reduced motion に対応している。

演出は **1 回の抽選につき 1 シーケンス** に集約します。ホバーやセクション出現などの細かいアニメーションは足しません。

## シーケンス

| #   | 内容                              | 時間  |
| --- | --------------------------------- | ----- |
| 1   | ボタン押下: 筐体が沈む            | 120ms |
| 2   | カプセル落下 + バウンド（spring） | 600ms |
| 3   | 溜め（カプセルが震える）          | 300ms |
| 4   | 開封: カプセルが割れてカードへ    | 400ms |
| 5   | 着地の余韻                        | 200ms |

合計 約 1.6s。**レアリティ制がないため演出時間は結果に依存しない固定値**です。

## タスク

- [ ] `motion` を導入する（`npm i motion`）
- [ ] `src/features/gacha/sequence.ts` にシーケンスを実装する
  - `useAnimate` で命令的に記述する
  - `AnimatePresence` + `layoutId` でカプセル → カードの形状を引き継ぐ
- [ ] 演出中は画面タップ / Esc / Space でスキップ可能にする
- [ ] スキップ手段は初回のみテキストで案内する
- [ ] `prefers-reduced-motion: reduce` に対応する
  - シーケンス全体を **150ms のクロスフェード**に置換（結果は同一）
  - カプセルの震えと着地の余韻は描画しない
  - **結果の提示タイミングは変えない**
- [ ] 連打しても破綻しないことを確認する

## StyleX との併用

- レイアウト・配色・タイポは全て StyleX。
- **Motion が触るプロパティは `transform` / `opacity` / `filter` に限定**し、StyleX 側で同じプロパティを指定しない。
- `motion.div` には `{...stylex.props(styles.x)}` を展開し、`style` prop は Motion に明け渡す。

## アクセシビリティ

- 演出中の中間状態（カプセルの落下など）は読み上げない（`aria-hidden`）。
- 結果は `role="status"`（`aria-live="polite"`）の領域に、**演出完了時に一度だけ**テキストを流す（例: `"no-debugger, correctness"`）。
- 連打時は live region の内容をクリアしてから差し替え、読み上げの積み上がりを防ぐ。
- 抽選後もフォーカスは「回す」ボタンに留める。
