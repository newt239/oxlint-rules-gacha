## 進め方

- 1 フェーズを 1 つの PR にする必要はありません。目的ごとにコミットを分けてください。
- 各フェーズの完了時に `npm run codecheck`・`npm run test`・`npm run build` が通ることを確認します。
- 実装ルール（ディレクトリ構成・StyleX の使い方・禁止事項）は [AGENTS.md](../AGENTS.md) を参照してください。

## 変えてはいけない前提

- **サーバー側に状態を持たない**。DB・認証・ランキング・投稿機能は将来も作りません。
- **10 連ガチャを作らない**。複数枚の結果には固有 URL がなく、共有に動的 OGP が要るためです。共有先は常にルール詳細ページです。
- **レアリティを持たない**。カテゴリは結果に添える属性情報で、排出率とは無関係です。
- **ルール説明文を翻訳しない**。翻訳するのは UI 文言だけです。
