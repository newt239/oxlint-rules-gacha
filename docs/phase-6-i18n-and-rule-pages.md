## i18n

**UI 文言のみを翻訳し、ルールの説明文とコード例は英語原文のまま表示します。** 870 件の説明文を翻訳・維持するコストが個人開発の範囲を明確に超えるためです。

- [ ] `src/i18n/en.ts`（既定。キーの正）と `src/i18n/ja.ts` を作る
- [ ] `src/i18n/index.ts` に `getDictionary(lang)` と型定義を置く
- [ ] キーの型は `en.ts` から生成し、**`ja.ts` に不足キーがあれば型エラーにする**
- [ ] ライブラリは入れない。複数形・日付書式は `Intl` で足りる
- [ ] 日本語 UI では説明の直前に「oxc 公式の原文（英語）です」という注記を 1 行置く
- [ ] 辞書は Server Component で読み込み、Client Component には**使うキーだけを props で渡す**
- [ ] 言語スイッチャーはヘッダに置き、選択を localStorage に保存して初期表示に反映する
- [ ] **言語の自動判定は行わない**。既定は英語

## 日本語フォント

フェーズ 0 では Baloo 2 + Geist Mono のみ接続しています。Zen Maru Gothic は next/font のメタデータ上 `japanese` サブセットを持たないため、`subsets: ["latin"]` では日本語グリフが配信されない可能性があります。

- [ ] Zen Maru Gothic を接続し、**実際に日本語が表示されるか確認する**
- [ ] 配信されない場合の代替案
  - 別の日本語フォントを使う
  - `next/font/local` でサブセット化した woff2 を同梱する
  - 日本語 UI はシステムフォントに任せる
- [ ] `new-cap` の `capIsNewExceptions` にフォント関数名を追加する（`.oxlintrc.json`）
- [ ] `[lang]/layout.tsx` で言語に応じて body のフォント変数を切り替える

## ルール詳細ページ

`/[lang]/rules/[plugin]/[name]`。共有の着地点になるページです。

- [ ] **完全にサーバーで描画し、クライアント JS をほぼ持たせない**
- [ ] `generateStaticParams` で 870 件 × 2 言語を列挙する
- [ ] `generateMetadata` で title / description / `alternates.languages`（`hreflang`）を出力する
- [ ] **公式ドキュメントへのリンクを上部に置き、一次情報ではないことを明示する**
- [ ] 「出典: oxc プロジェクト（MIT）」と原典へのリンクを明記する
- [ ] 説明文は原文をそのまま表示し、改変しない
- [ ] URL のプラグイン名は oxlint のルール ID 側（`jsx-a11y`）に揃える。ドキュメントのディレクトリ名（`jsx_a11y`）ではない
